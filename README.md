# qishui-apk

汽水音乐自建抓取服务的 Android WebView 壳：打开即连家里服务器 `http://192.168.1.3:8107`。

抓取在服务器上跑（Docker 镜像 `weleone/qishui-music:latest`），手机只负责显示和粘贴链接。

首次打开会让填服务器地址，之后可在菜单里改地址或刷新。

当前版本 v1.0.12：内置欢迎页。首次打开还没选过服务器时，不再弹管理框配一片空白，直接进深色欢迎页（“欢迎使用汽水抓取”+ 绿色“选择服务器”按钮，点开服务器管理）；服务器连不上时也进欢迎页，显示“当前地址无服务”+ 地址，同样有个“选择服务器”按钮，不用再去点右上角 ⚙。

v1.0.11（未发 Release，被 v1.0.12 取代）：无服务页提示改成屏幕正中间。

v1.0.10：WebView 底色改成深色，还没连上服务器时不再一片白；无服务页也改成深色底，与汽水页一致。

v1.0.9：右上角 ⚙ 改成白色（汽水页是固定深色底，黑色看不见）；默认服务器改成 `http://192.168.1.3:8107`；长按服务器多一个“编辑”按钮，改地址不用删了重加。

v1.0.8：右上角 ⚙ 是透明按钮；服务器管理里每行显示连通状态（✓ 绿=通、× 红=不通、…=检测中），点行或点圆点切换；服务器不通时显示“当前地址无服务”专设页，点右上角 ⚙ 重新选择。
